Backfill summaries and analysis

Go through every story already in the database and write what is missing: article summaries and analyses, the story summary and the deep report (rewritten when the story has gained articles since). Runs in the scheduler between pipeline runs: it waits for the main model, stops by itself 10 minutes before the next run and does not start again afterwards. Stopping is safe at any point; the next start carries on from what is still missing.
