Search mode queries NewsAPI's /everything endpoint with the query terms. Top headlines mode queries /top-headlines with the country and category instead; the unused fields are cleared on save. GNews is queried alongside NewsAPI using its own query/category values, because the two providers don't share a category vocabulary. Labels must be unique — they key each fetch's per-run metrics.
